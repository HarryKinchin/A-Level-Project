# A-Level-Project: A revision quizzer website

Full documentation for this project is in the pdf within the project, in the file [`NEA_Documentation.pdf`](NEA_Documentation.pdf)

## 🚀 Overview

Revise Wizz was developed as a solution to inefficient revision planning and poor tracking of exam board specifications among students. It provides an intuitive graphical user interface (GUI) coupled with a secure relational database backend, featuring spaced repetition algorithms, priority sorting, and visual progress analytics.

## ✨ Key Features

* **User Authentication & Authorization:** Secure password hashing (argon2) and personalized student accounts.

* **Interactive Study Dashboard:** Dynamic filtering, sorting by exam topic urgency, and active recall task tracking.

* **Automated Analytics:** Generates  progress reports to visualize syllabus completion and student confidence.

* **Data Persistence:** Fully relational SQLite database ensuring robust record-keeping and data integrity.

## 🛠️ Technology Stack

* **Programming Language:** Python 3.10+

* **GUI Framework:** HTML, CSS, and JS for a modern native look

* **Database:** SQLite3 with custom Object-Relational Mapping (ORM)

* **Testing & Version Control:** Git & GitHub
